# Clippy Videos

Bem-vindo ao Clippy Videos, uma rede social voltada para compartilhamento de vídeos e interação entre usuários. O projeto foi desenvolvido com Python e Flask, e utiliza diversas bibliotecas do ecossistema Python para garantir a funcionalidade da aplicação.

## Sobre o projeto

O Clippy Videos foi criado em 09/09/25 com o nome "Play Videos". No início, o projeto era apenas um teste, mas acabou se tornando uma rede social oficial em 11/09/25. Depois, o nome foi alterado para "Clip Engine" e, por fim, chegou ao nome atual: "Clippy Videos".

## Objetivo

A plataforma tem como objetivo conectar pessoas por meio de vídeos, permitindo:

- publicar conteúdos;
- interagir com outros usuários;
- acompanhar perfis e vídeos populares;
- criar uma comunidade dinâmica e colaborativa.

## Tecnologias utilizadas

- Python
- Flask
- Bibliotecas adicionais do Python

## Requisitos

Antes de iniciar o projeto, certifique-se de ter instalado:

- Python 3.x
- pip
- Git

## Instalação

Clone o repositório:

```bash
git clone https://github.com/Clippy-Videos-Inc/Clippy-Videos.git
cd Clippy-Videos
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Se necessário, também é possível instalar algumas bibliotecas manualmente:

```bash
pip install flask
pip install secrets
```

## Como executar

Após instalar as dependências, inicie a aplicação:

```bash
python app.py
```

Ou, se o projeto estiver usando o servidor do Flask:

```bash
flask run
```

Acesse a aplicação em:

```text
http://localhost:5000
```
